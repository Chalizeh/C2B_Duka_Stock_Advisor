# C2B Duka-stock-advisor
This app seeks to assist the IYF we academy canteen take stock and manage sales thus making it easier for student to view available product in real time.
The app objectives is to:
1. Enable the IYF We Can academy Canteen record daily sales.
2. Maintain a conversational history of stock updates.
3. Monitor remaining stock quantities.
4. Identify products that have reached their minimum stock levels.
5. Generate prioritised restocking recommendations.
6. Produce an end-of-session report summarising stock movements and sales.
